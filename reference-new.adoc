[[9-19-1-rc-13-july-2026]]
== 9.19.1 RC (13 luglio 2026)

La Release Candidate (RC) di Cloud Volumes ONTAP 9.19.1 è ora disponibile per la distribuzione e l'aggiornamento solo su Google Cloud. Questa versione non è disponibile per la distribuzione e l'aggiornamento su Amazon Web Services (AWS) e Microsoft Azure (Azure).



[[upgrade-notes]]
== Note sull'aggiornamento

Leggi queste note per ulteriori informazioni sull'aggiornamento a questa release.



[[how-to-upgrade]]
=== Come eseguire l'upgrade

Gli aggiornamenti di Cloud Volumes ONTAP devono essere completati dalla Console. Non dovresti aggiornare Cloud Volumes ONTAP tramite System Manager o la CLI. Ciò potrebbe compromettere la stabilità del sistema.

link:http://docs.netapp.com/us-en/bluexp-cloud-volumes-ontap/task-updating-ontap-cloud.html["Scopri come effettuare l'aggiornamento quando la Console ti avvisa"^] .



[[supported-upgrade-path]]
=== Percorso di upgrade supportato

Puoi eseguire l'aggiornamento a Cloud Volumes ONTAP 9.19.1 RC da 9.18.1 solo su Google Cloud. La Console ti chiederà di aggiornare i sistemi Cloud Volumes ONTAP idonei a questa release.


NOTE: Su AWS e Azure non ti verrà richiesto l'aggiornamento alla versione 9.19.1 RC perché questa versione non è disponibile per la distribuzione e l'aggiornamento per questi cloud provider.



[[downtime]]
=== Downtime

* L'upgrade di un sistema a nodo singolo mette il sistema offline per un massimo di 25 minuti, durante i quali l'I/O viene interrotto.
* L'upgrade di una coppia ha non comporta interruzioni e l'i/o rimane ininterrotto. Durante questo processo di upgrade senza interruzioni, ogni nodo viene aggiornato in tandem per continuare a fornire i/o ai client.
